@AGENTS.md

## What this is

A Next.js 16 web prototype of Knowunity's voice-based active-recall feature — students speak an answer, Knowie replies in text — built for a 2.5-week design sprint at 390px, dark mode, mobile-iOS-styled only.

## Hard rules

- Read `node_modules/next/dist/docs/` before writing any Next.js code. See AGENTS.md.
- Canvas is 390px, dark mode only, web app styled to look native iOS — not a native app. See `docs/platform-constraints.md`.
- Voice in, text out. See `docs/design-brief.md` (Hard constraints).
- Committed concept (single source, don't restate elsewhere): `docs/sprint-context.md`, "Committed concept" line.
- The recall engine is mocked: fake transcript, fake verdict, fake (but present) latency. See `docs/platform-constraints.md`, `docs/sprint-context.md`.
- Every screen is built from the `scaffold` component's slots — see `docs/design-system.md` §2.
- Every color, spacing, radius, and type value comes from `docs/tokens.json`; usage rules live in `docs/design-system.md`.
- Naming: lowerCamelCase for components/props/tokens, see `docs/design-system.md` §3 for the legacy exceptions.
- Contrast, touch-target, and reduced-motion requirements — see `docs/platform-constraints.md`.
- Design decisions already made are logged in `docs/sprint-context.md` — check before re-deciding something.

## Never

- Never invent a color/spacing/radius/type value not in `docs/tokens.json`.
- No CSS fallback values (`var(--token, #fallback)`). `docs/design-system.md` §4.
- Never build a screen outside the `scaffold` component (`docs/design-system.md` §2).
- Never build a new component when an existing one covers it, or invent one to fill a gap — flag the gap instead (`docs/design-system.md` §4).
- Never read a primitive color/value directly from a component — go through the semantic layer. `docs/design-system.md` §4.
- Never use anything but sentence case on labels, buttons, or headings. `docs/design-system.md` §4.
- Never use native APIs (haptics, native permission sheets, native nav transitions) — this is a web app. `docs/platform-constraints.md`.
- Never design or build a hover-only interaction — no hover on mobile. `docs/platform-constraints.md`.
- Never let Knowie speak, or auto-detect end-of-speech — push-to-talk with explicit stop only. `docs/design-brief.md`, `docs/voice-ux.md`.
- Never leave a required action without an escape route or non-voice fallback — "never trap the student." `docs/design-brief.md`, `docs/voice-ux.md`.
- Never build tablet, desktop, or RTL layouts, or real STT/AI judging — out of scope this sprint. `docs/sprint-context.md` (Not building).
- Never hand-recreate the Knowie mascot freehand — export the real component from Figma. `docs/design-system.md` §1.
- Never commit without keeping this file's first line (`@AGENTS.md`) intact.
