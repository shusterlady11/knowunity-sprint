# Component gaps

A running list of things built inline during a screen build because Storybook had no component for them. Read it before building a screen: if something you need is already here from another screen, build it properly as a component with a story instead, switch the earlier screen over to it, and mark it built here (`.claude/skills/build-screen/SKILL.md`, step 5).

| What | Built inline for | Notes | Status |
|---|---|---|---|
| Back-only top bar | 1 First-run splash (`src/app/start/page.tsx`) | `AppBar` always draws progress and XP. Figma's bar is loose layers: a back arrow on the left and a hidden Tertiary S "Skip". Built as a `ButtonIcon` Tertiary L (`ArrowLeftIcon`) in a 56px row. | Inline |
| Speech-bubble tail (Knowie speaking from behind a card) | 1 First-run splash (`src/app/start/page.tsx`, `start.css`) | `AnswerCard` `Default` matches Figma's bubble box (background/surface, Radius/400, Space/400 padding, Body M Regular) but has no tail. The tail is a 19×16 `background/surface` shape (`SpeechBubbleTailIcon`, exported from Figma's Vector 423) on the card's top edge, and the mascot sits behind the card's top. | Inline |
| Knowie peeking from behind a card (the overlap only, no tail) | 1 First-run splash (`start.css`, `.start__mascot`); 2 Mic primer (`src/app/mic/mic.css`, `.mic__speaker`, `.mic__card`) | Figma draws it as loose layers (a mascot frame and a card group), not a component. Both screens overlap the 2XL mascot's lower 44px. The splash puts Knowie at the left, the primer centers it. Second use: decide whether it becomes a component before screen 3, where the question screen uses it in the foreground. | Inline (2 screens) |
| Centered Headline S line | 2 Mic primer (`src/app/mic/page.tsx`, `.mic__primerText`) | Figma's primer text is a loose Headline S text layer. No `TextBlock` size uses Headline S (XL and L are larger headlines, M and S are body), so it's a styled `<p>`, as in the story "Scaffold › Mic permission". Settles D6. | Inline |
| Secondary button on a sheet | 2 Mic primer (`src/app/mic/mic.css`, `.mic__actions`) | `Button` Secondary fills with `background/surface`, the same as a `BottomSheet`, so it disappears on a sheet. Figma overrides the fill on this instance to `background/floating`; the screen does the same by styling `.button__face`. `BottomCTA` fixes the same problem inside its panel with `interactive/secondary` instead, so Figma uses two different fills for one problem. Every sheet with a Secondary button will need it (exit confirm). | Inline |
